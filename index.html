Регламент созвона

1. Слоты — 10:00–18:00 по местному времени менеджера, 1 час.
2. Созвон ставится только квалифицированному лиду.
3. За час до встречи клиенту уходит напоминание.
4. Недозвон — статус «Не дозвонились» + комментарий.
5. Перенос — кнопкой или мышкой, запись не удаляем.
6. Слоты вне 10–18 — по согласованию с менеджером.

Google Таблица подключено

Общая база созвонов: лист «Данные», зеркало на листах менеджеров (окно 10–18), журнал изменений, белый список доступа.

Вход через Google подключено

Авторизация по белому списку почт (лист «Доступ» таблицы). Сессия на 30 дней.

Google Календарь доступно

Постановка созвона создаёт событие в календаре менеджера с приглашением и напоминанием; удаление созвона отменяет событие. По умолчанию выключено — включите, когда команда будет готова.

GitHub Pages подключено

Хостинг дашборда: правка выкатывается за минуту, ссылка не меняется.

Яндекс Телемост ждёт токена

Автосоздание ссылки на видеовстречу при постановке созвона — без лимита 40 минут. Останется вставить токен Яндекса.

Zoom не планируется

На бесплатном тарифе лимит 40 минут на встречу — вместо него выбран Телемост.

Справка

Короткая шпаргалка по работе с графиком.

Постановка созвона

Оранжевая кнопка «+» или клик по пустому слоту. Обязательные поля — имя и контакт. Слот по умолчанию — первый свободный в окне 10–18.

Виды «Неделя» и «День»

«Неделя» — сетка одного менеджера на неделю. «День» — все менеджеры на один день: удобно быстро найти свободное время под клиента.

Перенос

Перетащите карточку мышкой в свободный слот или откройте её и нажмите «Перенести». Статус «Перенос» у запланированных ставится сам.

Нерабочее время

Клик по пустому слоту → «Нерабочий слот» (можно указать причину). Серые полосатые ячейки недоступны для записи. Вернуть — «Сделать рабочим».

Быстрый статус

Клик по статусу прямо на карточке в сетке — выбор из списка без открытия панели.

Часовые пояса

Слоты идут по местному времени менеджера (пояс — сноской над сеткой). При вводе города клиента в карточке показывается его текущее время.
